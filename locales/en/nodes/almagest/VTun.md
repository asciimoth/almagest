Creates one virtual netstack instance and exposes it as both an almagest/network and an almagest/tun endpoint. When it receives TunConfig, it uses Addrs, routes, source routes, MTU, and DNS. MTU zero enables automatic selection. A positive configured MTU is a ceiling and can be reduced by a received constraint. Source routes select the local address for each destination. VTun infers a source address for a plain route when the effective address suggestions contain the same IP family. An explicit local addrs value disables suggested source routes. An explicit DNS servers value has priority over a TUN DNS suggestion. If neither is set, VTun uses 8.8.8.8. TUN DNS suggestions are for simple topologies only; use almagest/dns nodes for DNS routing or policy.
